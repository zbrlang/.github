# ZBR

ZBR is a scripting language for Discord bots powered by a high-performance Rust runtime engine.
You write commands as plain `.zbr` files using ZBR functions, no boilerplate, no event handlers, no framework knowledge required.

## Core Repositories
- [zbrlang/zbr](https://github.com/zbrlang/zbr) - Core CLI & Runtime
- [zbrlang/zbr-website](https://github.com/zbrlang/zbr-website) - Main Website
- [zbrlang/zbr-webapp](https://github.com/zbrlang/zbr-webapp) - Webapp Editor
- [zbrlang/zbr-server](https://huggingface.co/spaces/zbrlang/zbr-server/) - Server Space
- [zbrlang/zbr-extensions](https://github.com/zbrlang/zbr-extensions) - Official Extensions
- [zbrlang/zbr-bot](https://github.com/zbrlang/zbr-bot) - Official Bot
